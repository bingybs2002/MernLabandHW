# AI / ML

### 1. What are AWS Bedrock and AWS SageMaker?

Amazon Bedrock is a fully managed, serverless service for using foundation models (such as Anthropic Claude, Amazon Nova, Meta Llama, Mistral) through one API, with tools for guardrails, knowledge bases (RAG), agents, and fine-tuning; you build generative-AI features without hosting models. Amazon SageMaker is AWS's managed machine-learning platform for preparing data and building, training, tuning, deploying, and monitoring your own custom ML models. In short: Bedrock to consume existing models via API, SageMaker to build and run your own models with full control of the ML lifecycle.
