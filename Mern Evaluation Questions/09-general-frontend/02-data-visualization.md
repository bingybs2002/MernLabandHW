# Data Visualization

### 1. What tools have you used for Data Visualization?

I have used Chart.js and Apache ECharts for dashboards, plus Recharts in React projects.

### 2. Give a brief comparison between Chart.js, Highcharts, D3.js

Chart.js: free, Canvas-based, easy to learn and fast to build common charts; less low-level control. Highcharts: feature-rich, polished, accessible, and strong for business dashboards; requires a commercial license. D3.js: very flexible and powerful for custom visualizations because it gives low-level control over data-driven DOM/SVG/Canvas rendering; higher learning curve and more code.
