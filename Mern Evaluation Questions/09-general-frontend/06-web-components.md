# Web Components

### 1. What is web component?

Web Components are a set of browser standards for creating reusable custom HTML elements with encapsulated behavior and styling that work in any framework. The main technologies are Custom Elements, Shadow DOM, and HTML templates.

### 2. What is Shadow DOM?

Shadow DOM provides an encapsulated DOM tree attached to a web component. Its internal markup and styles are isolated from the regular document DOM, which helps prevent CSS and DOM naming conflicts.

### 3. Name a web component framework

Examples include Lit, FAST, and Stencil. Lit is a lightweight library from Google for building standards-based Web Components.
